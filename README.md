# CyberLearn-SQLmap-SQL-Injectionn
CyberLearn adalah website edukasi cybersecurity yang membahas SQLmap dan SQL Injection, mulai dari konsep dasar, pengujian keamanan aplikasi web di lingkungan legal, hingga cara mencegah dan memperbaiki kerentanan database. Dilengkapi contoh kode aman, panduan praktik, dan kuis interaktif untuk meningkatkan pemahaman keamanan web secara etis.
