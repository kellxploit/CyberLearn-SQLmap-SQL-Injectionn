CYBERLEARN — SQLMAP & SQL INJECTION
Isi:
- index.html: halaman materi
- style.css: desain responsif dan tema gelap
- script.js: kuis, tema gelap, dan tombol salin
- README.txt: panduan

Menjalankan:
1. Ekstrak ZIP.
2. Buka index.html dengan browser.

Deploy ke Vercel:
1. Unggah file ke repository GitHub.
2. Buka https://vercel.com/new lalu impor repository.
3. Pilih Framework Preset: Other dan kosongkan Build Command.
4. Deploy. Pastikan semua file berada di root repository.

Keamanan:
Materi ini untuk edukasi. Lakukan pengujian hanya pada sistem milik sendiri atau yang telah memberi izin.
Contoh prepared statement menggunakan placeholder gaya Python DB-API; sesuaikan dengan driver yang dipakai.
